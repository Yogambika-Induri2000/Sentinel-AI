# Sentinel-AI: Real-Time TikTok Trend & Misinformation Intelligence Engine
**Sentinel-AI** is an end-to-end Data Engineering and Agentic Retrieval-Augmented Generation (RAG) platform built to stream, ingest, transform, vector index, and query TikTok video metadata and speech-to-text transcriptions in real time.

The architecture combines high-throughput distributed event streaming (**Apache Kafka** and **PySpark Structured Streaming**) with a hybrid relational and vector database store (**PostgreSQL + `pgvector`**). It features an **Agentic RAG Router** (**LangChain**) that dynamically executes **Text-to-SQL** for metric aggregations and **HNSW Cosine Similarity Search** for transcript semantics.

## Core System Features

* **Real-Time Streaming Engine:** Ingests high-frequency social video event streams via **Apache Kafka** and performs micro-batch transformations using **PySpark Structured Streaming** with explicit schema enforcement (`StructType`).
* **Hybrid Storage Layer:** Stores structured metadata in **PostgreSQL** alongside 384-dimensional dense vector embeddings generated by HuggingFace's `all-MiniLM-L6-v2` model in **`pgvector`**, indexed via **HNSW (Hierarchical Navigable Small World)** for sub-millisecond similarity lookups.
* **Agentic RAG Query Router:** Intelligent decision routing using **LangChain** that parses natural language user intent and dynamically delegates queries to either a **Text-to-SQL** execution engine or **Vector Cosine Distance** search.
* **Production Web API:** Microservice interface built on **FastAPI** featuring interactive OpenAPI/Swagger documentation (`/docs`) and health-check endpoints.
* **Fully Containerized Infrastructure:** Complete orchestration of local dependencies (Kafka, Zookeeper, PostgreSQL) via **Docker Compose**.
* **Automated Test Suite:** Integration and unit test coverage powered by **Pytest**.

## Tech Stack

| Domain | Technology | Description |
| :--- | :--- | :--- |
| **Event Streaming** | Apache Kafka | Distributed message queue for streaming video analytics |
| **Stream Processing** | PySpark Structured Streaming | Micro-batch parsing, schema enforcement, and JDBC sinking |
| **Database & Vector Index** | PostgreSQL + `pgvector` | Fact tables + HNSW cosine distance vector store |
| **Embeddings Model** | SentenceTransformers (`all-MiniLM-L6-v2`) | Local 384-dim dense vector generation |
| **GenAI & Agent Logic** | LangChain | Agentic tool binding (Text-to-SQL + Vector Search) |
| **REST API** | FastAPI & Uvicorn | Production web service framework |
| **Containerization** | Docker & Docker Compose | Infrastructure orchestration |
| **Testing** | Pytest | Integration testing suite |
